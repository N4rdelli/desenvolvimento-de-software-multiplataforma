## 📌 Sobre a Iniciativa
Este projeto centraliza e organiza os conteúdos desenvolvidos ao longo da graduação. Para otimizar a navegação e respeitar a natureza dos materiais, a estrutura foi dividida em dois ambientes integrados:

*   **Este Repositório (GitHub):** Destinado exclusivamente ao armazenamento de códigos-fontes utilizados durante as aulas, laboratórios práticos e projetos de desenvolvimento de software.
*   **Ambiente de Apoio (Google Drive):** Destinado a materiais teóricos, como slides disponibilizados pelos professores, bibliografias complementares, anotações de conceitos e registros de atividades.

## 🛠️ Como Navegar

A estrutura de arquivos do repositório reflete a organização da grade curricular:
*   Os códigos estão agrupados em pastas por período (ex: `terceiro-semestre/`).
*   Cada subpasta de disciplina possui sua própria estrutura isolada de projetos ou laboratórios.
*   Os diretórios de disciplinas contam com um arquivo `SUMMARY.md` detalhando os objetivos de aprendizagem e competências desenvolvidas na matéria.
