## Introdução a Node.js

### O que é Node.js?
O Node.js é um **ambiente de execução** para JavaScript do lado do servidor. Ele permite a criação de **aplicações** que **rodam diretamente no server side** e não depende de um navegador.

*Tradicionalmente, utilizávamos o JavaScript principalmente ne Front-End, para criar aplicações web interativas. Com o Node.js, podemos executar o JavaScript no Back-End, fora do navegador.*

### Como o Node.js funciona?
O Node.js funciona de maneira similiar ao ambiente de execução presente nos navegadores. Quando executamos um comando em JavaScript, o Node.js utiliza um motor para intrerpretar esse comando e fazer a sua conversão para a linguagem de máquina a ser executada pelo computador.

### Modularização em Node.js
O Node.js trabalha com o conceito de módulo, que visa organizar o código em partes pequenas e especializadas. A modularização também aplica o princípio de encapsulamento ao esconder o código e expor somente o necessário a outras partes da aplicação.

Originalmente o Node.js trabalhava com o sistema CJS (Common JS) de modularização, pois o JavaScript não tinha ferramentas específicas para isso. Posteriormente foi especificado o padrão geral de módulos do JavaScript, o EcmaScript Modules.
